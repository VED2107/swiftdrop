With a PC: scan once, then send either way.

SwiftDrop for Windows receives straight to a folder on disk and sends files back without staging them first. Phones connect from the browser; only the PC installs anything.

Connection dropped? It carries on.

After a drop, SwiftDrop sends only what's missing, never the whole thing again. With a PC it picks up by itself when the phone is back; between two phones, pair them once more and it continues from where it stopped.

Checked on arrival. Never on a server.

When a phone sends, each block is hashed on the way out and checked on arrival; a file only counts once its checksum matches, and a bad block is simply sent again. There is no SwiftDrop cloud: files go from one device to the other over your own network, even with no internet at all.

Questions

Do I need a PC to send between two phones?

No. Open phone to phone on both phones and each scans the other's code once. The files go directly between the phones; nothing passes through a PC or a server.

Do I need to install anything on my phone?

No. SwiftDrop runs in Safari or Chrome on your phone. Only the Windows PC runs an app, and only if you use one.

Does it work with Android?

Yes. iPhone and Android both work, with each other and with the PC: scan with the camera (or Google Lens), or type the six-character code the PC shows.

Do I need internet?

No. Both devices only need to be on the same Wi-Fi. With no Wi-Fi around, turn on one phone's hotspot and connect the other device to it.

Where do files end up on the receiving phone?

They're kept safely in the browser until you tap Save, which hands them to Photos or Files through the share sheet.

Windows asked about the firewall. Is that normal?

Yes. Allow SwiftDrop on private networks so your phone can reach your PC. If you install for all users, the installer sets this up for you.

Are there size limits?

Not in practice with a PC: big videos go straight to disk. Between phones, the receiving phone needs the free space. Either way, keep SwiftDrop on screen while it sends, since phones pause web pages in the background.

Will my iPhone photos stay HEIC?

The photo picker may convert them to JPEG. For originals, tap Options, then Current, in the picker, or send them from the Files app.
